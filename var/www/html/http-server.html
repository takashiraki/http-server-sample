HTTP Server

A minimal HTTP server implementation in C

Overview

This project is a simple HTTP server implementation written in C. It serves as an educational resource for understanding socket programming fundamentals and the HTTP protocol.

The server listens on port 8080 and responds with "Hello world" to incoming requests.

Features

Socket Communication

TCP/IP communication using POSIX standard socket API

HTTP/1.1 Compatible

Responds with basic HTTP/1.1 compliant responses

Docker Ready

Easy containerization and deployment with Dockerfile

Educational

Well-commented code ideal for learning low-level network programming

Tech Stack

C POSIX Socket API GCC Docker Ubuntu HTTP/1.1
